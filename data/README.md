# Данные глав викторины

Данные приложения разделены между каталогом и файлами отдельных глав. Вопросы оставлены в обычных JavaScript-файлах, поэтому проект не требует сборщика и использует классические `<script>`-загрузки.

## Добавление главы

1. Создайте `data/chapter-NN.js`, где `NN` — номер с ведущим нулём.
2. Зарегистрируйте набор вопросов через `window.LinuxQuizData.register(номер, вопросы)`.
3. Добавьте метаданные главы в список подготовленных глав в конце `data/catalog.js`. Эта запись заменит автоматически созданную заготовку для её номера.

Пример содержимого файла главы:

```js
window.LinuxQuizData.register(4, [
  {
    topic: "ТЕМА",
    question: "Текст вопроса?",
    answers: ["Вариант A", "Вариант B", "Вариант C", "Вариант D"],
    correct: 0,
    explanation: "Пояснение к правильному ответу."
  }
]);
```

Добавьте метаданные в массив глав в `catalog.js`:

```js
{
  number: 4,
  title: "Глава 4. Название",
  file: "data/chapter-04.js"
}
```

Заготовки для глав 1–36 уже перечислены в каталоге; для неподготовленных глав файлов вопросов нет. Проходной балл вычисляется автоматически как `Math.ceil(количество вопросов * 0.8)`. Например, для 10, 15 и 20 вопросов нужно соответственно 8, 12 и 16 правильных ответов.

Каждый вопрос должен содержать непустые `topic`, `question` и `explanation`, ровно четыре непустых `answers` и целый `correct` от 0 до 3. Некорректные или отсутствующие данные не ломают приложение: для главы будет показано сообщение.

Откройте `index.html` в браузере или запустите каталог проекта через любой статический веб-сервер. Сборка и установка зависимостей не нужны.
